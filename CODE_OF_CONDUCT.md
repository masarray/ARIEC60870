# Code of Conduct

ARIEC60870 follows a simple contribution standard: be respectful, technical, and evidence-oriented.

## Expected behavior

- Use clear, respectful language.
- Keep discussions focused on reproducible protocol behavior, source code, documentation, and release quality.
- Share sanitized traces, screenshots, and logs only when they do not expose customer, project, or site-sensitive information.
- Assume good intent when reviewing issues and pull requests.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing private project/customer data, credentials, network addresses, or raw traces that should not be public.
- Pushing vendor, commercial, GPL, or unclear-license source code into the clean-room Apache-2.0 codebase.

## Reporting

Use the repository issue tracker for normal project conduct concerns. Use `SECURITY.md` for security-sensitive reports.
