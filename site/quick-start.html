Quick start

Download, connect, review evidence, export PDF.

This page keeps the first run simple for authorized lab, FAT/SAT, or troubleshooting work: download the Windows ZIP, run ARIEC60870.exe, configure the endpoint, start the session, then export the report.

Download latest release Read full user guide

1. Download and open

Download ARIEC60870-vX.Y.Z-win-x64.zip, extract it, then double-click ARIEC60870.exe.

  • Do not run directly from inside the ZIP.
  • No installer is required.
  • No start batch file is required.

2. Choose protocol mode

Open Setup and choose the mode that matches the authorized test device.

  • IEC-101 serial for RTU/gateway serial checks.
  • IEC-103 serial for protection relay serial checks.
  • IEC-104 TCP/IP for TCP endpoint checks.

3. Enter approved settings

Use the project/device communication sheet. Avoid guessing settings from labels.

  • Serial: COM port, baud rate, parity, stop bits, addresses, ASDU profile.
  • TCP: server address, port, common address, ASDU profile.
  • Load a mapping profile when readable signal names are needed.

4. Start and review

Click Start, then review evidence from high-level rows down to protocol detail.

  • Operator Evidence, Value Viewer, Event Log.
  • Frame Trace, Diagnostics, Findings.
  • Confirm the evidence matches the approved test procedure.

5. Export PDF

Open Report, click Refresh if needed, then click Export PDF.

  • The report is generated by the built-in native PDF engine.
  • Review the PDF before sharing outside the project team.
