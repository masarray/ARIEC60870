FAQ

Questions before using ARIEC60870.

These answers clarify scope, licensing, operating system, protocol support, and safe use of exported evidence.

Download latest release Open GitHub repository

Is ARIEC60870 free?

Yes. ARIEC60870 is free and open source under Apache-2.0.

  • No license key.
  • No subscription.
  • No account requirement for trying the release package.

Does it support IEC-101, IEC-103, and IEC-104?

Yes, with practical evidence-oriented workflows for those IEC 60870 protocols.

  • IEC-101 serial telecontrol.
  • IEC-103 serial protection relay communication.
  • IEC-104 TCP/IP client testing.

Is it a full SCADA master?

No. It is a focused test and evidence analyzer.

  • One endpoint/session at a time.
  • Designed for FAT/SAT, commissioning, protocol visibility, and troubleshooting.
  • Not a production redundant master station.

How are signal names handled?

Decoded protocol fields come from traffic. Friendly names come from user-owned JSON mapping profiles.

  • No vendor database is embedded.
  • Mapping profiles should match approved project signal lists.
  • Raw frame evidence remains available.
