Protocol coverage

Three IEC 60870 workflows, one evidence model.

Each protocol has different field language. The UI separates serial protection, serial telecontrol, and TCP telecontrol so engineers can focus on relevant evidence.

IEC-101 serial

FT1.2 frames, unbalanced master workflow, link/common address, GI, optional clock sync, Type ID/COT/CA/IOA evidence, and ACD/DFC visibility.

IEC-103 relay

Protection relay serial testing with reset link/FCB, Class 1/Class 2 polling, FUN/INF evidence, relay timestamps, and user-owned mapping profiles.

IEC-104 TCP/IP

Client workflow with STARTDT/STOPDT/TESTFR visibility, I/S/U frame evidence, sequence counters, ASDU decoding, and reportable findings.
