How to use

Download, run, configure, review, export.

The first-run path is intentionally short so non-developer users do not need to choose between several launchers.

1. DownloadGet ARIEC60870-vX.Y.Z-win-x64.zip from GitHub Releases.
2. RunExtract the ZIP and double-click ARIEC60870.exe.
3. ConfigureOpen Setup and enter the approved project/device settings.
4. ReviewUse Operator Evidence, Value Viewer, Event Log, Frame Trace, Diagnostics, and Report.
5. Export PDFOpen Report, refresh the preview, and export the PDF file.
