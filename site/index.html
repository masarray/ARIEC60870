Protocol coverage

Three practical IEC 60870 workspaces, one evidence model.

Each protocol has different field language. The UI separates serial protection, serial telecontrol, and TCP telecontrol so users do not have to interpret irrelevant controls.

IEC-101 serial

FT1.2 frames, unbalanced master workflow, link/common address, GI, optional clock sync, Type ID/COT/CA/IOA evidence, and ACD/DFC visibility.

IEC-103 relay

Protection relay serial testing with reset link/FCB, Class 1/Class 2 polling, FUN/INF evidence, relay timestamps, and user-owned mapping profiles.

IEC-104 TCP/IP

Client workflow with STARTDT/STOPDT/TESTFR visibility, I/S/U frame evidence, sequence counters, ASDU decoding, and reportable findings.

FAQ

Questions before downloading ARIEC60870.

These answers help new users understand the scope, limitations, and safe evaluation path.

Is ARIEC60870 free?

Yes. ARIEC60870 is free and open source under Apache-2.0. There is no license key, account requirement, or subscription for trying the release package.

Which protocols are covered?

The app provides practical workflows for IEC 60870-5-101 serial, IEC 60870-5-103 serial protection relay communication, and IEC 60870-5-104 TCP/IP client testing.

Who should use it?

It is intended for protection, SCADA, RTU, gateway, commissioning, panel FAT, and substation automation engineers who need an evidence trail.

Does it require a vendor-specific database?

No. ARIEC60870 decodes protocol fields and can load user-owned JSON mapping profiles so displayed signal names follow the approved project signal list.

Can it export FAT/SAT evidence?

Yes. It provides operator-readable evidence, frame trace transparency, diagnostics, findings, and standalone report output that can be reviewed after the test session.
