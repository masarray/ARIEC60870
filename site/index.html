ARIEC60870 is a free Windows protocol tester and evidence analyzer for IEC 60870-5-101, IEC 60870-5-103, and IEC 60870-5-104. It keeps raw TX/RX frames visible, explains selected frame meaning, surfaces Smart Findings, records event/value evidence, and exports clean PDF reports for FAT, SAT, commissioning, troubleshooting, academic research, vendor evaluation, and commercial engineering work.

Why it is different

Not just a protocol capture. It turns communication into engineering evidence.

A link can be alive while data is silent. A command can be syntactically valid but never confirmed. A device can answer while using a different Common Address. ARIEC60870 keeps raw frames, decoded meaning, values, events, findings, and reports connected.

Protocol testerCheck IEC-101 serial, IEC-103 relay, and IEC-104 TCP/IP communication in an authorized engineering session.
Raw frame interpreterKeep TX/RX evidence visible and explain selected frame meaning without forcing every user to decode bytes manually.
Smart FindingsTurn CA mismatch, GI gaps, command timeout, missing ACTCON/ACTTERM, or unstable IEC-104 sessions into problem, proof, and next step.
Evidence reportGenerate native PDF evidence for FAT, SAT, commissioning, troubleshooting, homologation support, vendor comparison, and handover.
