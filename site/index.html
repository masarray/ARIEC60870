Why it is different

Not just a protocol capture. It turns raw communication into engineering evidence.

A link can be alive while application data is silent. A command can be correct but delayed by Class 1 congestion. A device can answer while using a different Common Address. ARIEC60870 keeps raw frames, values, events, findings, and reports connected so engineers can explain what happened.

Protocol testerCheck IEC-101 serial, IEC-103 relay, and IEC-104 TCP/IP communication in an authorized engineering session.
Raw hex interpreterKeep TX/RX hex visible and explain selected frame meaning without forcing every user to read protocol bytes manually.
Smart FindingsTurn CA mismatch, unknown IOA, GI gaps, bad quality, Class 1 congestion, command timeout, missing ACTCON/ACTTERM, or unstable IEC-104 sessions into problem, proof, and next step.
Evidence reportGenerate a native PDF report for FAT, SAT, commissioning, troubleshooting, homologation support, certification attachments, vendor comparison, and handover.
