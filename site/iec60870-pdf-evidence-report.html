Evidence report

IEC 60870 PDF evidence report without exhausting manual paperwork.

ARIEC60870 turns a reviewed IEC 101, IEC 103, or IEC 104 session into a native PDF evidence package. Use it for FAT, SAT, commissioning, troubleshooting, homologation support, vendor comparison, and handover when allowed by the project procedure.

Report contents

Readable, traceable, and reviewable evidence.

The report connects raw protocol evidence with decoded values, event logs, findings, and engineering notes so the test story does not need to be rebuilt manually.

Session summaryProtocol mode, endpoint, timing, and test context.
Values and eventsDecoded values, SOE-style changes, quality, timestamps, and mapping-assisted names.
Trace proofRaw TX/RX frames and selected-frame interpretation.
Smart FindingsProblem, proof, likely cause, and next step.
