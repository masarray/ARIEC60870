Smart Findings

What it means

Problem → proof → likely cause → next step.

ARIEC60870 is not only a protocol tester. It tries to make the evidence easier to act on by connecting raw frames, event logs, addresses, quality flags, and session behavior to practical findings.

ProblemA short statement of what looks wrong.
ProofThe frames, counters, addresses, quality flags, or events that support the finding.
Likely causeA practical explanation such as wrong CA, missing IOA mapping, incomplete GI, or timing behavior.
Next stepA check or correction to try before escalating.

Typical examples

Findings that reduce confusing protocol troubleshooting.

CA mismatchThe endpoint responds, but the ASDU Common Address does not match the expected profile. Check device configuration and ARIEC60870 setup.
Incomplete GIGeneral Interrogation starts but the expected snapshot is missing or incomplete. Check CA, Type ID expectation, polling policy, and event drain.
Command confirmation missingA command was sent but ACTCON, feedback, or ACTTERM is not visible. Check command type, IOA, CA, select/execute policy, and device support.
IEC-104 session unstableTCP may be reachable while STARTDT, TESTFR, sequence acknowledgement, or reconnect behavior is not healthy.
