Download

Download one Windows ZIP and run one desktop EXE.

ARIEC60870 is distributed as a simple self-contained Windows package for users. The normal path is not source build, not installer setup, and not several launch scripts: download the ZIP, extract it, run ARIEC60870.exe.

Correct release asset

Choose the Windows package named like:

  • ARIEC60870-vX.Y.Z-win-x64.zip
  • This is the user-facing release package.
  • Do not use the GitHub source-code ZIP unless you intend to build the project yourself.

What is inside

The package is optimized for normal engineering users.

  • ARIEC60870.exe — the Windows desktop app.
  • README_RELEASE.txt — first-run notes.
  • docs/, samples/, profiles/, license, notices, and changelog.

Integrity files

Release assets include supporting files for safer distribution.

  • SHA256SUMS.txt for file verification.
  • SPDX JSON dependency SBOM.
  • Build provenance attestation generated by the release workflow.

System requirement

The public release targets Windows x64 desktop users.

  • Use the release package on Windows.
  • The WPF desktop app requires Windows.
  • Build from source requires .NET 8 SDK.

Install steps

No installer flow. Keep it simple.

The package is portable-style: choose a folder, extract, and run. If Windows SmartScreen appears, verify the source and checksum before continuing according to your organization policy.

1. Download from GitHub ReleasesUse the latest release page linked above. Avoid third-party mirrors unless your organization controls the mirror.
2. Extract the ZIPExtract to a local folder such as a project tools folder. Do not run directly from the compressed archive viewer.
3. Run ARIEC60870.exeDouble-click the executable and open Setup to enter approved endpoint settings.
4. Keep release files togetherKeep license, notices, documentation, samples, and checksum files with the executable when sharing internally.
