Protocol coverage

IEC-101, IEC-103, and IEC-104 workflows with one evidence model.

ARIEC60870 is not a black-box tester. It keeps practical protocol evidence visible so engineers can explain startup behavior, General Interrogation, values, events, frame trace findings, and report output.

IEC 60870-5-101 serial

Use IEC-101 mode for authorized serial RTU or gateway checks.

  • FT1.2 fixed and variable frame visibility.
  • Master-side startup and General Interrogation evidence.
  • Type ID, COT, common address, IOA, value, quality, and timestamp review.
  • Serial setup with COM port, baud rate, parity, stop bits, link address, and ASDU profile.

IEC 60870-5-103 relay serial

Use IEC-103 mode for protection relay serial communication checks.

  • Reset link and FCB handling visibility.
  • Class 1/Class 2 polling evidence.
  • ACD/DFC visibility and event drain review.
  • FUN, INF, DPI, measurand, relay timestamp, and user-owned mapping profile support.

IEC 60870-5-104 TCP/IP

Use IEC-104 mode for authorized TCP endpoint checks.

  • STARTDT, STOPDT, TESTFR, I/S/U frame visibility.
  • Sequence counter evidence for session review.
  • Common ASDU decode for values, events, and command-related evidence.
  • Server IP, TCP port, common address, and ASDU profile configuration.

One evidence model

Different protocol transports are shown through a consistent evidence workflow.

  • Operator Evidence for summary-level review.
  • Value Viewer and Event Log for data/event behavior.
  • Frame Trace and Diagnostics for deeper analysis.
  • Native PDF evidence report for review and handover.

What this means in practice

Protocol support is evidence-oriented, not a claim to replace every tool.

The product is deliberately focused on single endpoint testing and evidence review. It is not a production SCADA master, not a gateway, and not a redundant communication system.

Supported focusStartup communication, General Interrogation behavior, received values, events, diagnostics, raw frame visibility, user mapping, and PDF reports.
Not the scopeProduction control center operation, multi-master redundancy, gateway service, vendor-specific database replacement, or certification authority for formal acceptance.
Best useUse ARIEC60870 as a transparent engineering evidence tool beside the approved FAT/SAT or troubleshooting procedure.
