Alur command IEC-101

Command bukan satu frame saja. Command adalah pertukaran protokol singkat yang seharusnya menghasilkan confirmation, feedback, dan evidence selesai.

SelectOpsional pada select-before-operate. Device disiapkan untuk command.
ExecutePermintaan operate. Address, COT, qualifier, dan IOA harus benar.
ACTCONActivation confirmation. Slave menerima atau menolak activation.
Feedback / ACTTERMPerubahan process value dan termination menunjukkan command selesai atau belum.

Yang dicek di ARIEC60870

Gunakan aplikasi untuk menghubungkan penjelasan dengan evidence frame.

1Jika ACTCON hilang, cek link state, CA, IOA, command type, dan flow control.
2Jika ACTCON ada tetapi feedback tidak berubah, protokol bisa benar sementara proses lapangan gagal.
3Report ARIEC60870 menjaga cerita command tetap utuh.
TX10 49 01 4A 16request link status
RX10 0B 01 0C 16ACD=1, Class 1 waiting
TX10 7A 01 7B 16request Class 1 data
RX68 ... 16event or command confirmation

Ikuti evidence berikutnya.

Belajar protokol lebih mudah ketika setiap konsep terhubung ke frame, counter, address, value, event, atau finding yang terlihat.
