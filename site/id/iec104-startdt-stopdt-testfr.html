Kontrol session IEC-104

IEC-104 bukan hanya TCP open. Session aplikasi harus dimulai dengan STARTDT, diawasi dengan TESTFR, dan diikuti lewat frame I/S/U.

Artinya

STARTDT, STOPDT, TESTFR, frame I/S/U

TCP connect hanya membuktikan socket terbuka. Data transfer dimulai setelah STARTDT. Data ASDU dibawa I-frame, acknowledgement terlihat di S-frame, dan U-frame mengontrol session.

STARTDTMemulai application data transfer setelah TCP connect.
STOPDTMenghentikan application data transfer.
TESTFRMenguji session saat traffic sedang sepi.
Frame I/S/UI-frame membawa ASDU, S-frame acknowledge, U-frame kontrol session.

Contoh frame IEC-104

Contoh ini memakai U-frame, I-frame, dan S-frame IEC-104, bukan contoh IEC-101 serial.

TXSTARTDT actMaster meminta data transfer dimulai
RXSTARTDT conDevice mengkonfirmasi data transfer
TXI-frame ASDUGeneral Interrogation activation dengan Common Address sesuai setup
RXS-frameAcknowledgement untuk sequence I-frame
TXTESTFR actTest supervision session
RXTESTFR conResponse supervision

Yang dicek di ARIEC60870

Hubungkan session control dengan evidence frame.

ARIEC60870 membantu melihat apakah STARTDT dikonfirmasi, sequence di-acknowledge, dan TESTFR dijawab sehingga engineer tidak hanya mengandalkan status TCP connect.
