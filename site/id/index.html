Uji IEC 101/103/104 dan ubah raw frame menjadi evidence engineering.

ARIEC60870 adalah protocol tester dan evidence analyzer Windows yang 100% gratis untuk IEC 60870-5-101, IEC 60870-5-103, dan IEC 60870-5-104. Aplikasi ini menjaga raw TX/RX frame tetap terlihat, menjelaskan arti frame penting, menampilkan Smart Findings, merekam event/value evidence, dan membuat PDF report untuk FAT, SAT, commissioning, troubleshooting, penelitian akademik, evaluasi vendor, dan pekerjaan engineering komersial.

Bukan tester biasa

Bukan sekadar capture protokol. ARIEC60870 mengubah komunikasi mentah menjadi evidence engineering.

Link bisa hidup, tetapi data aplikasi diam. Command bisa benar, tetapi terlambat. Device bisa menjawab, tetapi memakai Common Address berbeda. ARIEC60870 menjaga raw frame, value, event, finding, dan report tetap tersambung agar engineer bisa menjelaskan apa yang terjadi.

Protocol testerCek komunikasi IEC-101 serial, IEC-103 relay, dan IEC-104 TCP/IP di session engineering yang authorized.
Raw hex interpreterRaw TX/RX hex tetap terlihat, lalu frame terpilih dijelaskan agar user tidak harus membaca byte protokol secara manual.
Smart FindingsMengubah CA mismatch, GI gap, command timeout, ACTCON/ACTTERM tidak muncul, atau session IEC-104 tidak stabil menjadi problem, proof, dan next step.
Evidence reportBuat native PDF report untuk FAT, SAT, commissioning, troubleshooting, homologation, lampiran sertifikasi, evaluasi vendor, dan handover.
