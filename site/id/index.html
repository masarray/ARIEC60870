Kenapa dibuat

Karena banyak masalah protokol sudah terlihat di frame sebelum jelas di SCADA.

Link bisa hidup, tetapi data aplikasi diam. Command bisa benar, tapi terlambat karena Class 1 terlalu ramai. Device bisa menjawab, tetapi memakai Common Address berbeda. ARIEC60870 menjaga detail seperti ini tetap dekat dengan engineer.

Protocol flow

ACD bukan sekadar bit. ACD menentukan langkah master berikutnya.

Pada IEC-101 unbalanced, master normalnya tidak polling Class 1 terus-menerus. Master mengambil traffic regular, membaca response secondary, lalu mengambil Class 1 saat outstation memberi tanda ada data prioritas.

TX10 49 01 4A 16request link status
RX10 0B 01 0C 16ACD=1, Class 1 waiting
TX10 7A 01 7B 16request Class 1 data
RX68 ... 16event or command confirmation
