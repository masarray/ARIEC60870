Kenapa dibuat

Karena banyak masalah protokol sudah terlihat di frame sebelum jelas di SCADA.

Link bisa hidup, tetapi data aplikasi diam. Command bisa benar, tapi terlambat karena Class 1 terlalu ramai. Device bisa menjawab, tetapi memakai Common Address berbeda. ARIEC60870 menjaga detail seperti ini tetap dekat dengan engineer.

Protocol flow

ACD bukan sekadar bit. ACD menentukan langkah master berikutnya.

Pada IEC-101 unbalanced, master normalnya tidak polling Class 1 terus-menerus. Master mengambil traffic regular, membaca response secondary, lalu mengambil Class 1 saat outstation memberi tanda ada data prioritas.

Baca ACD/DFCBaca polling class
TX10 49 01 4A 16request link status
RX10 0B 01 0C 16ACD=1, Class 1 waiting
TX10 7A 01 7B 16request Class 1 data
RX68 ... 16event or command confirmation

FAQ

Pertanyaan yang biasanya muncul sebelum memakai tool.

Jawaban singkat dan praktis sebelum download atau membuka test session.

Apakah ARIEC60870 gratis?

Ya. Source publik berlisensi Apache-2.0 dan paket Windows dapat dicoba tanpa license key, akun, atau subscription.

ARIEC60870 dibuat untuk apa?

Aplikasi ini dibuat untuk evidence engineering IEC 60870: membaca frame, value, event, General Interrogation, command, findings, dan PDF handover.

Apakah ini pengganti SCADA master?

Tidak. Ini analyzer evidence engineering, bukan SCADA produksi, gateway, atau master station permanen.

Bisa dipakai untuk FAT atau SAT?

Bisa, selama test memang authorized dan sesuai prosedur project. Aplikasi membantu review evidence, sedangkan acceptance tetap mengikuti prosedur FAT/SAT resmi.

Apakah mendukung IEC 60870-5-101?

Ya. Workflow IEC-101 meliputi setup serial, evidence link, General Interrogation, value/event decode, frame trace, ACD/DFC, dan evidence command.

Apakah mendukung IEC 60870-5-103?

Ya. Workflow IEC-103 fokus pada evidence komunikasi relay proteksi, reset link, class polling, event relay, function information, timestamp, dan mapping.

Apakah mendukung IEC 60870-5-104?

Ya. Workflow IEC-104 mencakup TCP client evidence, STARTDT/STOPDT/TESTFR, frame I/S/U, sequence counter, decode ASDU, dan report.

Apa arti ACD di IEC-101?

ACD adalah Access Demand pada response link dari slave/outstation. Jika ACD=1, device memberi tanda bahwa ada data Class 1 yang menunggu.
