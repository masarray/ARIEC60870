# Support

ARIEC60870 is an open-source engineering tool. The best support path is a small, reproducible issue with sanitized evidence.

## Before opening an issue

1. Try the latest release.
2. Check `docs/QUICK_START.md` and `docs/TROUBLESHOOTING.md`.
3. Confirm the selected protocol mode, COM/TCP settings, address sizes, COT size, CA size, IOA size, and GI option.
4. Remove customer, project, station, IP, and device-identifying information from logs or screenshots.

## Good issue content

- Protocol mode: IEC-101, IEC-103, or IEC-104.
- Transport: serial or TCP/IP.
- Expected behavior.
- Actual behavior.
- Sanitized frame trace or screenshot.
- App version and Windows version.
- Steps to reproduce.

## Security-sensitive reports

Do not open public issues for security-sensitive findings. Follow `SECURITY.md`.
