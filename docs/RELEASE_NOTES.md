**Published 21 November 2026.** IEC-101 Event Log now displays `3 · spontaneous (buffer)` only when a verified original FC10 Class-1 request/FC8 response has ACD=1 (more Class-1 data pending). The suffix disappears when an exact matched response reports ACD=0. This is **not** proof that an individual event was originally in an RTU FIFO or how old it is. IEC-101 field widths now persist independently of IEC-103/104, Connection Setup/Frame Details are more compact, and source-qualified command/redundancy presentation is clearer.

**Upgrading from older registered program-folder installations:** close all IEC sessions and capture operations, then run the **official v3.6.19 installer directly** to migrate from `Programs/ARIEC60870` to `Programs/ArSee`. Do not manually uninstall or delete `%LOCALAPPDATA%/ARIEC60870`, the historical user-owned workspace containing saved profiles, signal lists and captures. The older in-app updater cannot safely relocate its executable. Existing canonical ArSee installations update in place.

**Boundary:** real Windows updater and install-folder migration FAT passed on release source, but one real-RTU screenshot is **not** full IEC/SCADA conformance, 2/4-channel hardware isolation, universal FIFO detection or site-specific scaling certification. The former [v3.6.18 release](https://github.com/masarray/arsee/releases/tag/v3.6.18) is still available as immutable history.
