ACD adalah Access Demand pada response link dari slave/outstation. Jika ACD=1, device memberi tanda bahwa ada data Class 1 yang menunggu.

DFC adalah Data Flow Control. Jika DFC=1, device memberi tanda bahwa sementara tidak siap menerima data tambahan.

Normalnya tidak. Siklus IEC-101 unbalanced yang sehat memakai polling Class 2 untuk traffic reguler dan mengambil Class 1 saat ACD menunjukkan data prioritas menunggu.

Penyebab umum adalah congestion di Class 1: event atau data analog cyclic masuk prioritas tinggi terlalu ramai sehingga confirmation command ikut tersendat.

Common Address mengidentifikasi station/group ASDU, sedangkan link address ada di layer link. Mencampur keduanya sering membuat komunikasi silent atau ditolak.
