FAQ

Pertanyaan yang biasanya muncul sebelum memakai ARIEC60870.

Jawaban jelas tentang scope produk, protokol yang didukung, ACD/DFC, class polling, report, lisensi, dan penggunaan engineering yang aman.

Apakah ARIEC60870 gratis?

Ya. Source publik berlisensi Apache-2.0 dan paket Windows dapat dicoba tanpa license key, akun, atau subscription.

ARIEC60870 dibuat untuk apa?

Aplikasi ini dibuat untuk evidence engineering IEC 60870: membaca frame, value, event, General Interrogation, command, findings, dan PDF handover.

Apakah ini pengganti SCADA master?

Tidak. Ini analyzer evidence engineering, bukan SCADA produksi, gateway, atau master station permanen.

Bisa dipakai untuk FAT atau SAT?

Bisa, selama test memang authorized dan sesuai prosedur project. Aplikasi membantu review evidence, sedangkan acceptance tetap mengikuti prosedur FAT/SAT resmi.

Apakah mendukung IEC 60870-5-101?

Ya. Workflow IEC-101 meliputi setup serial, evidence link, General Interrogation, value/event decode, frame trace, ACD/DFC, dan evidence command.

Apakah mendukung IEC 60870-5-103?

Ya. Workflow IEC-103 fokus pada evidence komunikasi relay proteksi, reset link, class polling, event relay, function information, timestamp, dan mapping.

Apakah mendukung IEC 60870-5-104?

Ya. Workflow IEC-104 mencakup TCP client evidence, STARTDT/STOPDT/TESTFR, frame I/S/U, sequence counter, decode ASDU, dan report.

Apa arti ACD di IEC-101?

ACD adalah Access Demand pada response link dari slave/outstation. Jika ACD=1, device memberi tanda bahwa ada data Class 1 yang menunggu.

Apa arti DFC di IEC-101?

DFC adalah Data Flow Control. Jika DFC=1, device memberi tanda bahwa sementara tidak siap menerima data tambahan.

Apakah master harus polling Class 1 terus?

Normalnya tidak. Siklus IEC-101 unbalanced yang sehat memakai polling Class 2 untuk traffic reguler dan mengambil Class 1 saat ACD menunjukkan data prioritas menunggu.

Kenapa command IEC-101 bisa lambat?

Penyebab umum adalah congestion di Class 1: event atau data analog cyclic masuk prioritas tinggi terlalu ramai sehingga confirmation command ikut tersendat.

Apa itu Common Address?

Common Address mengidentifikasi station/group ASDU, sedangkan link address ada di layer link. Mencampur keduanya sering membuat komunikasi silent atau ditolak.

Apakah aplikasi membawa database vendor relay?

Tidak. Data protokol berasal dari traffic, sedangkan nama sinyal dibaca dari mapping profile JSON milik user.

Apakah bisa export PDF?

Ya. Workspace Report bisa export native evidence PDF untuk review dan handover.

Apakah report bisa langsung dibagikan?

Sebaiknya cek nama station, IP address, nama sinyal, dan label project dulu karena report bisa memuat data sensitif.

Apakah ini conformance tester tersertifikasi?

Tidak. Ini analyzer dan learning-friendly evidence tool, bukan certified IEC conformance test suite.
