Kontrol session IEC-104

IEC-104 bukan hanya TCP open. Session aplikasi harus dimulai, disupervisi, di-acknowledge, dan diuji.

STARTDTMemulai data transfer setelah TCP connect.
STOPDTMenghentikan data transfer tanpa harus langsung menutup TCP.
TESTFRMengawasi session saat tidak ada data berguna mengalir.
Frame I/S/UI-frame membawa ASDU, S-frame acknowledge, U-frame kontrol session.

Yang dicek di ARIEC60870

Gunakan aplikasi untuk menghubungkan penjelasan dengan evidence frame.

1Socket bisa open tetapi application transfer belum start.
2Sequence mismatch menunjukkan masalah acknowledgement atau state tracking.
3ARIEC60870 menampilkan kontrol session bersama evidence ASDU.

RX10 0B 01 0C 16ACD=1, Class 1 waiting
