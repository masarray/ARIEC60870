Common Address vs Link Address

Link address ada di link layer. Common Address ada di ASDU. IOA mengidentifikasi information object di dalam ASDU.

Link addressDipakai link layer untuk menjangkau outstation di serial line.
Common AddressDipakai application layer untuk mengidentifikasi station atau group ASDU.
IOAMengidentifikasi object seperti measured value, indication, atau command point.
Ukuran profilePanjang COT, CA, dan IOA harus cocok dengan profile device.

Yang dicek di ARIEC60870

Gunakan aplikasi untuk menghubungkan penjelasan dengan evidence frame.

1Device bisa menjawab link-layer tetapi menolak data aplikasi karena CA salah.
2IOA salah sering terlihat sebagai point tidak berubah atau unknown information object.
3Gunakan mapping profile untuk menerjemahkan raw address ke nama sinyal project.
TX10 49 01 4A 16request link status
RX10 0B 01 0C 16ACD=1, Class 1 waiting
TX10 7A 01 7B 16request Class 1 data
RX68 ... 16event or command confirmation
