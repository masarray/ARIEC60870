Event relay IEC-103

IEC-103 sering dipakai untuk komunikasi relay proteksi. Evidence biasanya berupa event relay, function information, dan data fault, bukan sekadar process point umum.

Reset linkMaster membuat state komunikasi bersih.
Class pollingData relay bisa muncul melalui perilaku Class 1/Class 2.
Event relayInformasi proteksi dapat membawa function dan information number.
TimestampWaktu event dari relay penting untuk review fault dan sequence.

Yang dicek di ARIEC60870

Gunakan aplikasi untuk menghubungkan penjelasan dengan evidence frame.

1Jangan berharap evidence IEC-103 sama seperti process value IEC-101 berbasis IOA.
2Perhatikan function/information field dan timestamp relay.
3ARIEC60870 membantu membuat evidence protokol relay lebih terbaca.
TX10 49 01 4A 16request link status
RX10 0B 01 0C 16ACD=1, Class 1 waiting
TX10 7A 01 7B 16request Class 1 data
RX68 ... 16event or command confirmation

Baca berikutnya

Ikuti evidence berikutnya.

Belajar protokol lebih mudah ketika setiap konsep terhubung ke frame, counter, address, value, event, atau finding yang terlihat.
