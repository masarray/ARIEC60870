Quick start

Run a focused IEC 60870 evidence session in minutes.

This quick-start page keeps the first run simple: download the Windows release, choose the protocol mode, configure the endpoint, run General Interrogation when needed, then review evidence and export the report.

Download latest release Open GitHub repository

1. Download and extract

Use the release package from GitHub Releases. Start from a local folder, not directly from inside the ZIP.

  • Download the portable or single-file Windows ZIP.
  • Verify SHA256SUMS.txt when release integrity matters.
  • Run Start-ARIEC60870.bat.

2. Select the protocol workspace

Choose the protocol that matches the device under test so the setup screen exposes only relevant fields.

  • IEC-101 serial for RTU/gateway serial telecontrol.
  • IEC-103 serial for protection relay communication.
  • IEC-104 TCP/IP for client/server telecontrol sessions.

3. Configure addressing and timing

Use the approved project communication parameters rather than guessing addresses from labels.

  • Set COM port or TCP endpoint.
  • Set link address, common address, timeout, and interoperability profile.
  • Load a user-owned mapping profile if readable signal names are needed.

4. Review and export evidence

Use the workspace from high-level evidence down to raw frame trace.

  • Check Operator Evidence first.
  • Open Value Viewer, Event Log, Diagnostics, and Frame Trace.
  • Use Report Preview for handover notes or browser save-as-PDF.
