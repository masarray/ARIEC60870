What it means

IEC-103 relay events

IEC-103 is commonly used for protection relay communication. The evidence often looks like relay events, function information, and fault-related data instead of generic telecontrol points.

Reset linkThe master establishes a clean communication state.
Class pollingRelay data can appear through Class 1/Class 2 behavior.
Relay eventProtection information may include function and information numbers.
TimestampRelay-side event time matters for fault and sequence review.

What to check in ARIEC60870

Use the software to connect the explanation to the frame evidence.

2Check function/information fields and relay timestamps carefully.
