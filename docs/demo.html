What to look for

The demo follows the evidence path engineers actually need.

It is not a decorative animation. Each chapter maps to a real commissioning or troubleshooting workflow where raw protocol proof must remain visible.

01

Start from an authorized session

Use project-approved connection settings and make the communication state visible before interpreting symptoms.

02

Read TX/RX meaning without hiding raw frames

The line monitor keeps the raw frame as audit evidence while the selected-frame interpreter explains the protocol meaning.

03

Turn symptoms into Smart Findings

Common Address mismatch, GI gaps, command acknowledgement problems, and IEC-104 session symptoms become proof-backed findings.

04

Prepare the evidence report

Values, events, trace interpretation, and findings are organized into a PDF report for FAT, SAT, commissioning, support, and handover.
