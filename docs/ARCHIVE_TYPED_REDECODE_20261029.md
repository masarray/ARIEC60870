# Archived evidence typed replay — 2026-10-29

Selected .ariec captures record decoder field widths per frame and manifest SHA-256. Opening a capture verifies frames.jsonl integrity before rendering. IEC-101 and IEC-104 archived raw bytes are decoded using the original recorded link/COT/CA/IOA widths through the shared Master/Core parser, not another WPF decoder. Legacy captures without width metadata remain readable as preserved summary/raw evidence, but the UI must not invent missing typed fields. Malformed frames keep raw evidence and cannot be presented as good quality. Master regression tests cover valid serial, invalid checksum, legacy missing widths and IEC-104 I-format command replay. Full multi-object event/values reconstruction and entire report graph parity are subsequent acceptance gates.
