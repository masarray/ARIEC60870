What it means

IEC-104 session control

IEC-104 is not only TCP open. The application session must be started, supervised, acknowledged, and tested.

STARTDTStarts data transfer after TCP connection is established.
STOPDTStops data transfer without necessarily closing TCP immediately.
TESTFRKeeps the session supervised when no useful data is flowing.
I/S/U framesI-frames carry ASDUs, S-frames acknowledge, U-frames control the session.
