FAQ

Questions engineers usually ask before using ARIEC60870.

Clear answers about product scope, supported protocols, ACD/DFC, class polling, reports, licensing, and safe engineering use.

Is ARIEC60870 free?

Yes. The public source is Apache-2.0 and the Windows release can be used without a license key, account, or subscription.

What is ARIEC60870 made for?

It is made for IEC 60870 engineering evidence: checking frames, values, events, General Interrogation behavior, commands, findings, and PDF handover records.

Does it replace a SCADA master station?

No. It is an engineering evidence analyzer, not a production SCADA system, gateway, or permanent master station.

Can I use it during FAT or SAT?

Yes, when the test is authorized and the project procedure allows it. The app helps prepare and review evidence, while formal acceptance remains under the approved FAT/SAT procedure.

Does it support IEC 60870-5-101?

Yes. IEC-101 workflows include serial setup, link evidence, General Interrogation review, value and event decoding, frame trace, ACD/DFC visibility, and command evidence.

Does it support IEC 60870-5-103?

Yes. IEC-103 workflows focus on protection relay communication evidence, link reset, class polling, relay events, function information, timestamps, and mapping-assisted review.

Does it support IEC 60870-5-104?

Yes. IEC-104 workflows cover TCP client evidence, STARTDT/STOPDT/TESTFR visibility, I/S/U frame behavior, sequence counters, ASDU decoding, and report output.

What does ACD mean in IEC-101?

ACD is the Access Demand bit in the secondary link response. When it is set, the outstation is telling the master that Class 1 data is waiting.

What does DFC mean in IEC-101?

DFC is the Data Flow Control bit. When it is set, the outstation is indicating that it cannot accept more data at that moment.

Should the master poll Class 1 all the time?

Normally no. A healthy unbalanced IEC-101 cycle uses Class 2 polling for regular traffic and drains Class 1 when ACD indicates pending high-priority data.

Why does an IEC-101 command become slow?

A common cause is Class 1 congestion: events or cyclic analog data are configured so aggressively that command confirmation has to compete with too much high-priority traffic.

What is Common Address?

Common Address identifies the ASDU station/object group, while link address belongs to the link layer. Mixing the two is a common source of silent or rejected communication.

Does the app include vendor relay databases?

No. Protocol data comes from traffic, while readable signal names come from user-owned JSON mapping profiles.

Does it export PDF?

Yes. The Report workspace exports a native evidence PDF for review and handover.

Can the report be shared directly?

Review station names, IP addresses, signal names, and project labels first. The report is evidence, so sensitive project data should be checked before distribution.

Is it a certified conformance tester?

No. It is an engineering analyzer and learning-friendly evidence tool, not a certified IEC conformance test suite.
