# Documentation Archive

This folder preserves historical engineering notes and detailed release notes without overloading the public README or main documentation index.

- `release-notes/` contains legacy per-version release notes.
- `engineering-notes/` contains historical audits, UX notes, forensic notes, and design notes.

The current public entry points are `README.md`, `CHANGELOG.md`, `docs/QUICK_START.md`, `docs/TROUBLESHOOTING.md`, `docs/ARCHITECTURE.md`, and `docs/VALIDATION_MATRIX.md`.
