# ARIEC60870 v3.4.0 — Open Capture + ASE-like Workflow UX

## Added

### Open ARIEC capture

The left rail now includes:

- `Open Cap`

Users can open `.ariec` / `.zip` capture containers generated by the selected Line Monitor capture feature.

The app loads `frames.jsonl` into Protocol Trace and enters:

- `Offline Capture Review`

New diagnostics:

- `ARIEC-CAPTURE-OPENED`
- `ARIEC-CAPTURE-OPEN-FAILED`

### Main workflow rail

The left rail now exposes the capture workflow directly:

- Setup
- Connect
- Export
- Open Cap
- Save Cap
- Clear
- Signals

This makes capture actions visible without reading a manual.

### Protocol Trace as primary workspace

Protocol Trace is now the default workspace and appears first in the navigation row. Evidence Summary becomes the second workspace.

### Click-drag selection

Protocol Trace supports mouse drag selection across rows in addition to Ctrl/Shift multi-selection.

### Compact Command Preview

The command preview block is compacted so command buttons are no longer pushed down by long explanatory text. Longer explanations are moved into tooltips/diagnostics.

## Preserved

- Selected-block `.ariec` capture export
- Capture ZIP container: `manifest.json`, `frames.jsonl`, `retention.json`, `report.md`, `hash.txt`
- SHA256 frame ledger marker
- Protocol proof layer
- GI coverage matrix
- Trace verbosity governor
- True ring buffer UI runtime
